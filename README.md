# MiniHider

Simple addon that hides various frames (configurable) on your UI for a cleaner/less cluttered look.

Currently you can hide:

- Player resting "zzz" and flashing animation.
- Prestige badges (bottom left of player/target/focus frames).
- Player corner icon (bottom right golden arrow icon).
- Player level text.
- Blizzard arena frames.
- Blizzard arena frames title.
- Blizzard party frames title.
- Bags bar.
- Micro menu.
- Social icon (a.k.a quick join toast button above the chat frame).
- Stance Bar (druid forms, warrior stances).
- Hot keys text on your action bars.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
